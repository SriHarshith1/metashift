# Golden set review — LoL 26.19, 26.20, 26.21

Labeling rules:
- Every line with an arrow (⇒ or →) is one change.
- A text-only line counts only when it changes gameplay. Bug fixes, tooltip fixes, notes and the 26.20 scoreboard list are skipped.
- `stat` is the label before the colon in the notes. `direction`: buff = stronger, nerf = weaker, adjust = mixed or unclear.
- Only Summoner's Rift sections (Arena, ARAM: Mayhem, Classic are dropped by the pipeline).

Please check the **direction** column most. Change a row by telling me the patch and row number.
