# LoL win, pick and ban rate sources

Checked on 2026-10-25. lolalytics.com is not used. Its robots.txt allows generic crawlers (`User-agent: *`, `Allow: /`) but carries a Cloudflare content signal (`ai-train=no, use=reference`) and blocks many AI crawlers, and we found no terms-of-use page (`/terms` and `/tos` return 404; only `/info/privacy` exists). The site offers no documented or stable JSON endpoint for all-rank win, pick and ban rates per patch. Its data calls are internal and sit behind Cloudflare, so a scraper would be fragile and would depend on unclear permission. Because permission is unclear, we treat scraping as not allowed. `LolAdapter.fetch_stats` therefore always raises `StatsUnavailable("lolalytics not used: see STATS.md")`, and the baseline stage reads the previous patch's stats from `data/lol/<patch>/stats.csv` (columns `entity,win_rate,pick_rate,ban_rate,tier`; the file sits in the current patch folder and holds the previous patch's numbers). Export that CSV by hand from any source whose terms allow it (for example the numbers you read on a stats site).
